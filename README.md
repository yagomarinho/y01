# Y01

A functional kernel for AI agents: agnostic of infrastructure and application,
with effects at the shell, extensible through plugins.

> **Status:** early design. Nothing here is usable yet, and the API will change.

## Development

Requires Node 22.18 or later and pnpm 12.6.0 (pinned in `devEngines`).

```bash
pnpm install
pnpm test
pnpm lint
pnpm typecheck
pnpm build
```
